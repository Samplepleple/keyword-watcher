手機通知

先把這個網頁加入主畫面，才能收到通知：

  1. 點 Safari 下方的「分享」按鈕
  2. 選「加入主畫面」
  3. 從主畫面打開「關鍵字監控」，再按「開啟通知」

需要 iPhone iOS 16.4 以上，並使用 Safari 開啟（LINE 等 App 內的瀏覽器不行）。

這個瀏覽器不支援網頁通知。iPhone 請更新到 iOS 16.4 以上，並用 Safari 開啟這個網址。

開啟後，有新的關鍵字內容就會跳出通知，點通知會直接打開文章。

✅ 這支手機已開啟通知

剛開啟的話，幾分鐘內會收到一則「通知已開啟」確認。

通知被拒絕了。請到 iPhone「設定」→「通知」→「關鍵字監控」重新允許。

監控中的網站

第一次修改需要 GitHub 金鑰（只要貼一次，這支手機會記住）

  1. 打開 GitHub 金鑰產生頁
  2. Repository access 選「Only select repositories」→ 選 keyword-watcher
  3. Permissions → Repository permissions → Contents 設為「Read and write」
  4. 按「Generate token」，複製金鑰貼到下面
